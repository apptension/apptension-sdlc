# Ticket reference for a pull request

Read when `implement-issue` writes the PR body at step 10.

| Reference | Content |
|---|---|
| Closing keyword | `Closes #N`, whatever the `Issue tracker` binding. It moves the board card to Done on merge, and the merge closes the issue |
| Jira ticket link | None. A GitHub issue under a Jira tracker gets no Jira link |
| A ticket filed during the run | `Filed: #N` |
