# Working from a Plan handoff

Read when the plan comes from the ticket's Plan handoff comment, not
from a gate run in this session.

The handoff holds every part, whoever posted it. Work from its recorded
track. By its track body:

| Track body | Do |
|---|---|
| Spec and plan (design track, full mode, architectural) | Right after step 3, write the spec verbatim to `docs/superpowers/specs/<YYYY-MM-DD>-<slug>-design.md` and the plan to `docs/superpowers/plans/<YYYY-MM-DD>-<slug>.md` |
| Short design (bounded) or plan (reduced mode) | Work from its approved text |
| Direct-track reason or micro-track named surface | Work from the ticket and that line |

Done when every file the table names is written, before step 6 starts.
